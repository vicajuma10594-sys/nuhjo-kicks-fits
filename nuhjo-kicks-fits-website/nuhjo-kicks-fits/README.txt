ONLINE M-PESA / CARD CHECKOUT
The website is prepared to use IntaSend's hosted checkout for KES payments, which can show M-Pesa and card methods enabled on your account. Online payment is NOT live until you complete the following steps:
1. Create an IntaSend account and finish its business verification/onboarding.
2. In the IntaSend dashboard, find Settings → API Keys and copy the PUBLISHABLE key (it starts with ISP.../ISPubKey_ depending on key format). Use the publishable key only in the website.
3. In index.html, find `const INTASEND_PUBLISHABLE_KEY = 'ADD_YOUR_INTASEND_PUBLISHABLE_KEY';` and replace the placeholder with your publishable key. Never add an IntaSend secret key to index.html or share it in chat.
4. Test checkout using IntaSend's test/sandbox key first. Replace with the live publishable key only after testing and account approval.
5. A return to the website is NOT proof of payment. Check the transaction in the IntaSend dashboard before dispatching. For a production shop, add a secure backend/webhook to record and verify payment events.
